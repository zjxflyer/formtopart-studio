# Source fidelity gates for inherited and corrected drawings

Use these targeted gates with structure.md, source-symbols.md and acceptance.md, not as a duplicate universal audit on every edit. Source observations, physical geometry, annotations and output visibility remain separate layers.

## Whole original evidence, not self-generated expectations

Before protecting an inherited body as unchanged, compare the original component footprint and connected/coincident contributors with current actual exports. A selected native-ID list, legacy crop, generated expected inventory or reproducibility pass cannot certify complete source coverage. Classify function/owner before size or thinness filtering; broad caps and small functional fixtures can both be physical.

For a new or risky reconstruction method, complete one recognizable whole-view pilot before batching. Useful horizontal and vertical dimensions must remain associated with actual objects and source witnesses. Diagnostic per-number stubs cannot replace their physical context. Keep those diagnostics internal.

## Current mapping and source paint

Derive the CURRENT export transform from two independent source physical references before overlays; old helpers are not authority. Use the same verified mapping for geometry, grid marks and new dimension witnesses. Compare complete visible unions and junctions, not only changed IDs.

Read original fill, stroke, clipping and paint order. A white nonstroking knockout establishes occlusion, not a generic wall perimeter. Verify both required black/gray physical paint and genuine white voids; preserve actual leaves/jambs inside an opening. Do not erase or stroke a whole rectangular owner box without physical evidence. A checker must withdraw a wrong wall interpretation when source paint proves otherwise.

## Operations, fixtures and text

Inventory all source-owned operation fragments in own Plan entries and every own elevation. Preserve each panel's direction, endpoints, arms and pattern. Do not dash native dash fragments twice. Verify isolated operation ink or subtract identical frame paint so a cabinet border cannot satisfy missing tip visibility. Complete a source-supported common apex only within the user's appearance authorization; invent neither generic V marks nor hinges.

Omit decoration by complete evidenced ownership, not pale color or missing dimensions. Preserve source-supported functional basins, drains, taps, shelf/drawer profiles and connected aliases serving retained assemblies. Distinguish material texture from operation marks.

Check actual nonspace glyph ink and leader clearance. Zero/near-zero source glyph advance is an extraction limitation: use defensible baseline-projected native advance or isolated ink bounds without changing value, owner or witnesses. Nearby lines do not prove a character painted. Complete material words, code frames and source-face targets remain atomic associations.

## Scope and tests

Use a source-correct positive and meaningful missing/shortened/wrong-transform/filled-void/missing-tip/zero-paint defects through the same relevant actual export gate. Technical parity and two identical builds can share one source omission. Retain unchanged valid evidence only when input hashes/dependencies match and no contrary evidence exists.

Current owner presentation preference: compact external split-circle source-view clusters without blue view leaders or residual stubs. Keep genuine short wall/grid axes separate; actual source IDs/directions/view count control. Dimension lanes stay near the visible object with a readable gap. User amendments override these defaults.

Authorized necessary missing measurements may receive bounded provisional NTS review acceptance with supported method, endpoints and uncertainty, shown pale yellow. Original printed values remain source-printed in their own views despite conflicts. Unknown controlling facts still limit scope; never invent hidden hardware/depth or force conflicting chains closed.

These procedures support future work; they do not reopen historical drawings or certify fabrication. Adopted instructions, independently tested decision behavior and freshly verified customer geometry are separate claims.
