# Authority and applicability

Determine the project location, permit or contract date, occupancy, scope, governing authority, contract specifications, and adopted editions before stating that a requirement applies.

## Precedence for interpretation

1. Contract requirements, addenda, approved substitutions, customer legends, and explicit project notes control the submitted design language unless they conflict with mandatory law.
2. Coordinated views, details, schedules, and repeated project usage explain ambiguous marks.
3. The governing law or code applies only within its jurisdiction and effective scope. Flag conflicts for review; do not redesign the drawing.
4. A standard becomes mandatory when incorporated by law, regulation, contract, or specification. Otherwise describe it as guidance.
5. Software defaults and common drafting practice are weak interpretive evidence and never prove project geometry.

## Vancouver default

For projects in the City of Vancouver, start with the applicable Vancouver Building By-law and its transition provisions. Do not substitute the BC Building Code merely because it is newer; the Province states that the BC Building Code does not apply in the City of Vancouver. For projects elsewhere in British Columbia, start with the adopted BC Building Code and local requirements. National model codes are source models and references unless adopted or incorporated for the project.

Electrical work in British Columbia is governed separately through the BC Electrical Code and Technical Safety BC processes. A drawing showing lighting, receptacles, or concealed LED coordination is not proof of electrical compliance.

## Required citation metadata

For every relied-on source record:

- title and issuing organization;
- edition or version;
- jurisdiction and subject;
- source class;
- whether it is mandatory, specified, guidance, or unknown for this project;
- public URL or contract-document reference;
- access limitation such as paywall, account, preview-only, or full public text;
- date verified;
- relevant scope summary without copying protected text.

When the applicable edition cannot be established, state the uncertainty and the information needed to resolve it.
