# Delivery checks

Use a compact checklist with principle, evidence, status and scope for each applicable item. Add only triggered sheet-specific checks.

1. Required owned physical components, positions, profiles, openings and operations are correct; decorative omissions are evidenced.
2. Printed values/units/qualifiers, actual witness endpoints and object/datum associations are correct. Necessary authorized estimates are provisional and visually distinguished, with method and uncertainty retained.
3. Actual exported glyphs, small contours, operation tips, material names/targets and leaders are readable. Remove diagnostic miniatures, backend IDs and obsolete annotation bundles without hiding real geometry or necessary uncertainty.
4. Each sheet's packet begins with its own focused Plan, then only its own elevations. Repeated context is allowed; a shared Plan cannot substitute for individual ownership. Source view IDs/directions, genuine short grid references and current presentation preferences remain accurate.
5. Release files match the independent check's exact hashes and scope. Changing outputs or controlling inputs invalidates affected acceptance. Repeatability/parity alone does not establish original-source completeness.
6. Index has one row per sheet with current PDF/preview/folder pointers and truthful candidate/accepted/held status. Validate file targets and actual page order. Real browser clicking is distinct from static link validation; record unperformed access honestly.
7. Combined PDF follows manifest sheet order and own Plan-before-elevations order. Preserve exact page contents and boxes, expected page count and resolved bookmark/contents destinations. Test nonempty decoded data, not empty-stream hashes. User-requested extra pages must have explicit placement and scope.
8. State all omitted, provisional or held content; save release references and checkpoint. Customer layout-review scope does not establish fabrication readiness or site verification.

Owner presentation defaults: white surfaces, black true outlines, blue dimensions, pale-yellow supported estimates; no decorative floor/grain/tint clutter. Compact source-ID/direction view clusters stay outside objects without blue view leaders/stubs; true wall/grid identifiers remain separate. User instructions and actual source view count control, not a fixed four-view template.
