# Create

Read the current manifest, phase mapping, exact source and applicable verified lesson keys. Write only the assigned new revision. Use a compact task record: step, principle, evidence, result, scope; DONE/PENDING/BLOCKED/NA, with a reason for NA. Append only triggered sheet-specific checks.

1. **Source and ownership.** Identify exact view/object and amendments. Build required physical profiles, children, operation marks, dimensions and material associations from original source evidence independently of the renderer's selected-ID or generated-expected lists. Historical inventories are seeds, not proof.
2. **Reconstruction.** Preserve positions, real boundaries, connected/coincident contributors and genuine openings. Derive any source-to-current export transform from independent physical carriers, not an old helper layout. Replay fill/stroke/clip/paint order before calling a shape a wall. Check one complete recognizable pilot before a new or risky batch method.
3. **Dimensions.** Preserve original values, units, qualifiers, witness endpoints and actual object/datum ownership. A nearby annotation may belong to another room. Keep useful dimensions visibly associated with recognizable objects; auxiliary isolated stubs cannot replace them. Authorized estimates require a supported method/endpoints/uncertainty and the chosen provisional presentation, not invented hidden depth or hardware.
4. **Simplification and symbols.** Use evidenced owner families to omit decoration. Pale or undimensioned functional basins, taps, drains and physical cabinet parts remain when source-supported. Keep each panel's complete operation arms, direction, pattern and tip. Do not dash already fragmented dashes again or substitute generic V marks.
5. **Actual output self-check.** Compare whole source views and affected details with actual exported formats, including glyph ink, thin profiles, operation-only tips, own leaders and frame/code clearance. Reproducible exports can share the same source omission. Check all valid dimension/material/view/grid associations and customer-page cleanliness.
6. **Handoff.** Save immutable files, source/before/after evidence, changed scope and exact hashes. Batch material corrections within the available round. Hand over to independent Check, never award yourself acceptance.

Inherited unchanged evidence may be reused only when source, file hashes and dependencies remain valid and no counterevidence exists. The first FULL_REVIEW inspection still covers the whole sheet. A new verified lesson applies forward unless the user authorizes retrospective work.
